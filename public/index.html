抖音 / 快手 / 头条 / 小红书分享爬取

粘贴分享文案即可，支持抖音、快手、今日头条、小红书（xhslink.com/…）短链。抖音默认优先无水印直链。成片尾仍有平台贴片时可再用下方「去掉视频水印」。

Cookie（可选，仅短链无法直访时）

下载视频

iPhone：點保存到相册，在分享菜單選「儲存視頻」；或長按上方視頻預覽。

去掉视频水印

标配 OCR 自动框 + 逐帧 inpaint。建议先用「快速模式」验证效果，再决定是否开 AI 超分。抖音选「抖音角标」；豆包选「豆包 AI」。

像素坐标（可先选预设，再按预览微调）

下载处理后视频

批次圖片去水印（資料夾）

Windows / macOS：選資料夾批次處理，完成後下載 ZIP。

手機瀏覽器：多選圖片去水印，完成後點保存到相冊，在系統分享菜單選「儲存圖像」。

下載 ZIP

優先彈出系統分享；若無法彈出，會顯示預覽圖，長按圖片即可存入相冊。

手機打不開？幾乎都是 Windows 防火牆攔住了，請在電腦上：

  1. 打開資料夾 hongguo\scripts
  2. 雙擊 allow-firewall-8000.bat
  3. 彈窗點 是（允許管理員權限）
  4. 看到「已放行」後，手機再開上方地址
